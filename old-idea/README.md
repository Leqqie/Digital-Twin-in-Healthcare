Welcome to the code for our old idea: a hybrid model that will predict nocturnal glucose levels.

To run this script: All files should be downloaded. It is expected that you already possess the datafiles for OhioT1DM in the same filepath, but in a different folder (so you have a folder called old_model_code and a folder called data). 
_run_analysis.py_ is the only file you will have to run, but before that, you have to edit the filepaths at the bottom of the script to your personal filepaths (for data and results directories), which is also indicated with comments.
